# iOS source starter (not parity with Android)

SwiftUI app source supports prompt entry, offline schematic, photo picker,
PNG export and a local project list. No diffusion, ink engine or video runtime
is integrated on iOS. This is explicitly not the complete iOS product.

Use free Xcode on a Mac: New Project → iOS App → StudyForge, SwiftUI,
Swift, deployment target iOS 17. Replace the generated app source with
StudyForge/StudyForgeApp.swift (remove the generated ContentView.swift).
Choose your own unique bundle identifier. Run in the iOS simulator without
a paid developer membership. Personal-device signing and distribution have
Apple-imposed conditions; permanent broad iOS distribution cannot be promised
under a universally zero-cost workflow. No paid account is required by this source.

The iOS code has not been compiled in the Linux build environment.
